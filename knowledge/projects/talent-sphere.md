# Endava Talent Sphere

## Summary

I built and internally delivered an employee-management and workforce-insights application for Endava.

## Technical approach

- ReactJS frontend.
- Java Spring WebFlux backend with non-blocking APIs.
- PostgreSQL, REST APIs, and Caffeine caching.
- Employee information, organizational hierarchy, employee-data workflows, and workforce insights.
- CI/CD-based internal release coordination across frontend, backend, and database integration.

## Impact

I improved application response latency by approximately 87 percent, from about 3 seconds to about 400 milliseconds, through query tuning, indexing, asynchronous processing, caching, and connection management.

The application centralized employee-data access and workforce-management workflows for more than 5,000 internal users.
