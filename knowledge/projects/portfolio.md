# AI-Integrated Engineering Portfolio

## Summary

I designed and built this responsive engineering portfolio to let recruiters explore my experience, projects, skills, and outcomes through a focused conversational interface.

## Technical approach

- ReactJS and JavaScript.
- CSS Modules and a custom neo-brutalist design system.
- Modular component architecture, accessible interactions, mobile-first usability, and performance-conscious animation.
- Guided recruiter prompts, conversation states, contextual follow-ups, and full-page modal behavior.

## Agent roadmap

The portfolio's first agent phase uses ElevenLabs Agent, its hosted Knowledge Base RAG, and my cloned voice. The goal is a grounded first-person portfolio conversation without exposing confidential project information.

## What I learned

I wanted the portfolio itself to demonstrate the kind of product thinking I apply elsewhere: make technical depth easy to explore, keep the interaction focused, and design a clear path from information to action.
