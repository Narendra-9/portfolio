# QuickPark

## Summary

I built QuickPark, a vehicle parking-management web application, as an IIT Madras coursework capstone. I built it without AI-generated code to strengthen my understanding of backend architecture, authentication, database modeling, role-based workflows, and frontend integration.

## Technical approach

- Python, Flask, SQLAlchemy, Flask-Login, Flask-RESTful, SQLite, JavaScript, Bootstrap, and Chart.js.
- Parking lots, parking spots, reservations, users, and vehicle-based booking workflows.
- Secure registration and authentication, role-based access control, password hashing, CSRF protection, booking history, spending insights, occupancy tracking, and administration.
- Administrator flows for parking-lot management, reservation monitoring, user management, revenue analytics, and dashboards.

## What I learned

QuickPark gave me a practical full-stack foundation in secure application workflows, relational data, administration features, and documentation-driven debugging.
