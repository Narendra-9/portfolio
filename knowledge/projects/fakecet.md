# FakeCET

## Summary

I built FakeCET, an examination and college-counseling portal, as an early independent learning project without AI-generated code.

## Technical approach

- HTML5, CSS3, JavaScript, Java, SQL Server, OOP, database design, and Figma.
- Student registration, exam applications, payments, hall tickets, examinations, results, rank cards, counseling eligibility, college preferences, and seat allotment.
- Figma wireframes before implementation.
- Java domain models, workflow interfaces, object-oriented business logic, and custom validation exceptions.
- Relational SQL Server design for students, academics, payments, marks, colleges, branches, preferences, and allotments.

## What I learned

FakeCET helped establish my early foundation in user journeys, Java domain modeling, relational database design, frontend behavior, and hands-on debugging.
