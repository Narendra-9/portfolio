# Fitness Gear Store

## Summary

I built a fitness gear e-commerce platform during the GalaxE Solutions internship capstone. I developed it from first principles without AI-generated code to build a deep understanding of frontend architecture, backend services, relational data, and commerce workflows.

## Technical approach

- ReactJS, Java 17, Spring Boot, Spring Data JPA, SQL Server, REST APIs, WebSockets, JUnit, and Mockito.
- Product discovery, categories, cart, wishlist, checkout, profiles, order tracking, delivery details, reviews, and payment workflows.
- Layered backend with controllers, service and repository patterns, validation, email features, scheduled operations, and SQL Server persistence.
- Administration for products, categories, users, orders, delivery locations, banners, and statistics.
- Real-time product notifications using WebSockets.

## What I learned

The project strengthened my understanding of end-to-end commerce systems, layered Java design, API contracts, database persistence, testing, and manual debugging.
