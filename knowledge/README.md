# Portfolio Agent Knowledge Base

This directory is the source of truth for the public facts used by Narendra Vanapalli's portfolio agent.

Rules:

- Keep every statement public, verified, and suitable for a recruiter-facing portfolio.
- Prefer a focused source file over one large document.
- Update these Markdown files first, then synchronize them to the ElevenLabs Knowledge Base.
- Do not add confidential client details, private contact details, salary information, unpublished code, or uncertain metrics.
- If a fact is not documented here, the agent must say it does not have enough verified information to answer.

Each document includes frontmatter for review and retrieval organization.
